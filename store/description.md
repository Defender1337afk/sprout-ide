# Sprout IDE — описание для магазина

## Название
Sprout IDE

## Краткое описание (до 80 символов)
Пиши код на телефоне: 24 языка, совместные проекты и open-source сообщество

## Категория
Инструменты разработчика

## Полное описание

Sprout IDE — среда разработки, которая помещается в карман. Пиши код на 24 языках, запускай веб-страницы и JavaScript прямо на телефоне, работай над проектами вместе с друзьями и делись открытым кодом с сообществом. Всё — в живом дизайне Material 3 Expressive.

🌱 УДОБНЫЙ РЕДАКТОР
• Подсветка синтаксиса для Kotlin, Python, JavaScript, TypeScript, C, C++, C#, Java, Go, Rust, Swift, Dart, PHP, HTML, CSS и других языков
• Автоотступы, автозакрытие скобок, кавычек и HTML-тегов
• Номера строк, подсветка парных скобок, вкладки, отмена и повтор
• Поиск и замена, в том числе регулярными выражениями
• Панель символов над клавиатурой — фигурные скобки и точка с запятой в одно касание
• Масштаб текста щипком и автосохранение

▶️ ЗАПУСК
• Предпросмотр HTML-сайтов с вашими CSS и JS
• Запуск JavaScript со встроенной консолью и выводом ошибок
• Просмотр Markdown и SVG

👥 СОВМЕСТНЫЕ ПРОЕКТЫ
• Пригласите друзей по @юзернейму и пишите один проект вдвоём или всей командой
• Изменения участников приходят сразу после сохранения
• Если двое правили один файл, Sprout предложит выбрать, чью версию оставить

🌍 OPEN-SOURCE СООБЩЕСТВО
• Публикуйте проекты в профиль — только с открытым кодом и лицензией (MIT, GPL, Apache и другие)
• Оценивайте проекты звёздами и обсуждайте их в комментариях
• Клонируйте чужие проекты к себе одним нажатием и учитесь на реальном коде

🎨 ВАШ ПРОФИЛЬ И ВАШ СТИЛЬ
• Баннер с градиентом или картинкой, аватар, статус, ссылки на Telegram и GitHub
• Коллекционные бейджи и особые бонусы оформления
• Светлая, тёмная и AMOLED-тема, цвета обоев Material You, свой акцентный цвет
• 4 шрифта для кода, 10 цветовых схем, настройка форм, анимаций и размера интерфейса

📁 ПРОЕКТЫ
• 10 готовых шаблонов: веб-сайт, Python, Kotlin, Java, Node.js, C, C++, Go, Rust
• Дерево файлов, импорт файлов и ZIP-архивов, экспорт проекта в ZIP

Без аккаунта Sprout работает в гостевом режиме: все проекты хранятся на телефоне. Вход через Google открывает профиль, публикацию, совместную работу и сообщество.

Sprout IDE — свободное приложение с открытым исходным кодом под лицензией GNU GPL v3.
